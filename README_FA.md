# ali Studio — نسخه حرفه‌ای ویرایش لوگو

- 74 متریال متالیک چندمرحله‌ای: طلایی، نقره‌ای، کروم، برنز، مس، استیل، تیتانیوم، مشکی، قرمز، سبز، آبی، بنفش، رزگلد و ترکیبی.
- عمق سه‌بعدی، اکستروژن، bevel، سایه، هایلایت و نوارهای specular.
- ته‌رنگ فلزی قابل انتخاب برای تغییر رنگ پایه متریال بدون از بین بردن گرادیان و هایلایت‌ها.
- 12 حالت تایپ‌فیس بر پایه خانواده‌های سیستمی Android با fallback مناسب برای فارسی/عربی و حالت‌های مناسب لاتین.
- لایه‌ها، حذف/انتخاب لایه، Undo/Redo، زوم، چرخش و جابه‌جایی لمسی.
- وارد کردن تصویر از گالری با downsampling تا 4096px برای کاهش فشار حافظه.
- خروجی PNG شفاف 2048×2048.
- ذخیره و بازکردن پروژه ALI با نگهداری تنظیمات متریال، رنگ، فونت و تصویر URI.
- R8/ProGuard برای Release.

نکته: رندر متالیک فعلی Canvas-based است و PBR/GPU reflection واقعی نیست؛ با این حال چندمرحله‌ای است و صرفاً یک رنگ تخت نیست.
